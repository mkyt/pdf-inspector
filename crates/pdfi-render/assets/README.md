# Default CMYK profile

`FOGRA39L_coated.icc` stands in for DeviceCMYK (ISO Coated / FOGRA39,
offset printing on coated paper, close to GRACoL 2006). It is the file
of the TeX Live `colorprofiles` package (version 20181105), which Peter
Selinger generated from the free `FOGRA39L_coated.iccprofile.xml` with
colord's `cd-create-profile` and placed in the public domain; the
profile states "This profile is free of known copyright restrictions".
